# ASH-EM-Game

Like the popular BINGO game, but with a trivial twist. Each column is a different category: A = Arts (music & media), S = Science, H = History & Geography, E = English, M = Math.

Tiles are drawn at random. If 1+ players need the drawn tile, they compete to answer the question. Whoever calls "Ash 'Em" first gets to answer, and if they get it wrong, the tile remains unclaimed, and a new one is drawn. The first player to get a line (horizontal, vertical, or diagonal) of 5 wins. The game has a built-in tutorial with more extensive instructions on how to play. The game has modes for 1-5 players.

This program focused much on storing and updating player data in arrays and ArrayLists, associating "tile status" in one list with the corresponding tiles in another list using matching indices. Decomposition was used, with distinct tasks separated into individual methods with smaller helper methods.

As this program is a console-based application, knowledge and understanding of ANSI codes and print formatting were applied to achieve the card layout and design (e.g. tiles layout, colours differentiating player cards).

Research of each category was conducted to ensure a comprehensive understanding of the project's topic.
